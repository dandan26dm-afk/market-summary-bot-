# הסיפור של היום – סיכום שוק יומי לדיסקורד

הבוט רץ בכל יום מסחר בארה"ב ב-17:00 שעון ישראל. הוא מושך נתונים אמיתיים מ-Yahoo Finance, בונה תמונה ושולח אותה לערוץ בדיסקורד. בסופי שבוע ובחגים בארה"ב הוא לא שולח.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `market_bot.py` | הקוד הראשי. כל ההגדרות נמצאות בראש הקובץ. |
| `template.html` | העיצוב של התמונה: צבעים, גדלים ופריסה. |
| `requirements.txt` | הספריות שהבוט צריך. |
| `.github/workflows/market-summary.yml` | התזמון ב-GitHub Actions. |

## הקמה (פעם אחת)

1. **יוצרים webhook חדש בדיסקורד.** הישן נשלח בטקסט גלוי ולכן עדיף להחליף אותו. נכנסים להגדרות הערוץ ← Integrations ← Webhooks ← New Webhook, מעתיקים את הכתובת ומוחקים את הישן.
2. **יוצרים מאגר חדש ב-GitHub.** עדיף **Private**. בוחרים New repository ומסמנים Private.
3. **מעלים את הקבצים.** Add file ← Upload files ← גוררים את `market_bot.py`, `template.html`, `requirements.txt` ו-`README.md` ← Commit.
4. **יוצרים את קובץ התזמון.** Add file ← Create new file. בשם הקובץ כותבים בדיוק `.github/workflows/market-summary.yml` (התיקיות נוצרות לבד), מדביקים את התוכן ← Commit.
5. **שומרים את ה-webhook כסוד.** Settings ← Secrets and variables ← Actions ← New repository secret. בשדה Name כותבים `DISCORD_WEBHOOK_URL` ובשדה Secret מדביקים את כתובת ה-webhook.
6. **בדיקה.** לשונית Actions ← "סיכום שוק יומי לדיסקורד" ← Run workflow. אחרי 2–3 דקות התמונה אמורה להופיע בדיסקורד. הרצה ידנית שולחת מיד. מחוץ לשעות המסחר היא מציגה את יום המסחר האחרון.

מכאן הכול אוטומטי.

## איך זה עובד

- GitHub עובד לפי שעון UTC ולא מכיר את שעון הקיץ של ישראל. לכן יש שתי שורות תזמון, והקוד בודק איזו מהן מתאימה לעונה הנוכחית.
- התזמון מעיר את הבוט ב-16:30, והבוט ממתין ושולח בדיוק ב-17:00. ככה עיכובים של GitHub (בדרך כלל 5–20 דקות) לא משפיעים. אם GitHub מאחר ביותר מ-3 שעות, הבוט לא שולח באותו יום.
- **החג:** אם ל-S&P 500 אין נתון מהיום, הבורסה סגורה והבוט לא שולח.
- **הכותרת:** הבוט סורק את החדשות ב-Yahoo Finance מה-20 שעות האחרונות. הוא מעדיף כותרות על השוק כולו או על מניות מהרשימה שזזו חזק, ומדלג על "קליקבייט". אם אין כותרת מתאימה, הוא כותב משפט אוטומטי בעברית מהנתונים. מתחת לתמונה נשלח גם קישור לכתבה.
- **צבע הרקע** נקבע לפי ה-S&P 500: ירוק כשהוא עולה, בורדו כשהוא יורד, ואפור-כחלחל כשהשינוי קטן מ-0.2% לכל כיוון.
- **פס ה-VIX:** מתחת ל-20 מופיע "השוק רגוע יחסית". מעל 20 מופיע "סטטיסטיקה לטובתנו". מעל 30 מופיע "קנייה גם כשמגעיל".
- **אם משהו נכשל**, נשלחת לדיסקורד הודעה קצרה עם קישור לפרטים. עותק של כל תמונה נשמר 7 ימים בלשונית Actions.

## מקורות הנתונים (Yahoo Finance)

| בתמונה | סימול ב-Yahoo |
|---|---|
| S&P 500 | `^GSPC` |
| QQQ | `QQQ` |
| VIX | `^VIX` |
| RUSSELL | `^RUT` (Russell 2000) |
| RSP | `RSP` (S&P 500 במשקל שווה) |
| BTCUSD | `BTC-USD` |
| USOIL | `CL=F` (נפט WTI, חוזה עתידי) |
| US10Y | `^TNX` (תשואת אג"ח 10 שנים) |

השינוי היומי מחושב מול סגירת יום המסחר הקודם, בדיוק כמו ב-Yahoo.

## שינויים נפוצים (ב-`market_bot.py`)

- **להוסיף או להוריד מניה:** עורכים את `WATCHLIST`. התגית היא הטקסט האפור הקטן ליד הטיקר.
- **כמה מניות בכל צד:** משנים את `TOP_N`.
- **ספי ה-VIX:** משנים את `VIX_FEAR` ו-`VIX_PANIC`. הטקסטים נמצאים בפונקציה `vix_banner`.
- **מתי הרקע נחשב "ללא שינוי":** משנים את `FLAT_BAND`.
- **לבטל את הקישור לכתבה:** `SEND_NEWS_LINK = False`.
- **לשנות שעה:** משנים את `SEND_HOUR_IL`, וגם מזיזים את שתי שורות ה-cron בקובץ ה-workflow (ואת `CRON_SUMMER`/`CRON_WINTER`), כך שיתעוררו חצי שעה לפני.
- **צבעים וגדלים:** בראש `template.html`, במשתנים `--green`, `--red` וכו', ובמחלקות `mood-up`, `mood-down` ו-`mood-flat`.

## בדיקה במחשב (לא חובה)

```bash
pip install -r requirements.txt
python -m playwright install chromium
python market_bot.py --no-send              # נתונים אמיתיים, שומר market_summary.png
python market_bot.py --demo fear --no-send  # תצוגה עם נתוני דוגמה (calm / fear / panic)
```

## הערות

- Yahoo Finance לא מציע API רשמי. הבוט משתמש בספריית `yfinance`, שמתעדכנת כל הרצה. אם Yahoo משנה משהו והבוט נשבר, בדרך כלל עדכון של הספרייה פותר את זה.
- מאגר פרטי מקבל 2,000 דקות Actions בחודש בחינם. הבוט צורך בערך 35 דקות ביום, כלומר כ-800 בחודש.
